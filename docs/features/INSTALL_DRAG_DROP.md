# Install Drag & Drop for Project Reordering

## Run This Command

```bash
npm install @dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities
```

This installs the drag-and-drop library needed for reordering projects.

## After Installing

The reordering feature will be ready to use in the admin panel!

**Note:** If you get a permission error, try:
```bash
sudo chown -R $(whoami) ~/.npm
npm install @dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities
```
